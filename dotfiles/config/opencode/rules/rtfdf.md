# RTFDF — Read The F***ing Documentation First

- **When asked a question, don't guess. Check online first. Answers must be supported by proof.**
- Before recommending any configuration, command, syntax, or behavior, verify against the official source (man pages, official docs, upstream source code, project README). Do not invent or extrapolate.
- If you don't know, say you don't know — then look it up.
- Web search and webfetch are the first tools, not the last.
